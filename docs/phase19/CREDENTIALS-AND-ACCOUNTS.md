# Credentials, external accounts and costs: register

- **As of:** 2026-10-24, `main` at `413ff36`.
- **What this lists:** every credential, external account or paid service the
  code needs, with:
  - the exact configuration names the code reads, or names marked
    **proposed** where nothing reads them yet;
  - what each one blocks, and what can continue without it.
- **Nothing here is provisioned.** No credential, account or paid service has
  been created, and none may be without the owner's (and, for
  infrastructure, SRE's) authorisation.
- **Never in chat or Git.** Every secret is a file mounted from a Kubernetes
  Secret (the `*_FILE` names) or a workload identity. None is ever pasted into
  chat, a ticket or the repository.
- **Costs:** a cost is stated only where it was verified. "Unverified" means
  someone must check before enabling it.

## 1. Self-generated keys and secrets (no external account)

These are generated by SRE, stored as Kubernetes Secrets and mounted as files.
They incur **no external cost**, and they block **staging and production
only**: local development and CI use test keys generated in the tests.

| Name (read by the code today) | Service | Holds | Notes |
|---|---|---|---|
| `CS_IDENTITY_ACCESS_TOKEN_PRIVATE_KEY_FILE` | identity | The Ed25519 private key that signs access tokens | Rotation: `docs/runbooks/access-token-signing-key-rotation.md`, never exercised |
| `CS_IDENTITY_ACCESS_TOKEN_KID`, `…_ISSUER`, `…_AUDIENCE` | identity | Key id, issuer, audience | Configuration, not secret |
| `CS_IDENTITY_HMAC_SECRET_KEY_FILE` | identity | The HMAC key: OTP and refresh-token hashes, pseudonyms, subscriber ids | Has no rotation path until ADR-0030 is implemented |
| `CS_IDENTITY_DATABASE_DSN_FILE` | identity | PostgreSQL DSN (`verify-full`, explicit CA) | |
| `CS_IDENTITY_ENROLLMENT_CANONICAL_URL`, `CS_IDENTITY_REFRESH_CANONICAL_URL` | identity | The canonical `htu` URLs | Configuration |
| `CS_EDGE_API_ACCESS_TOKEN_PUBLIC_KEY_FILE`, `…_KID` | edge-api | The active verification key | |
| `CS_EDGE_API_ACCESS_TOKEN_PREVIOUS_PUBLIC_KEY_FILE`, `…_PREVIOUS_KID` | edge-api | The previous key, during rotation only | |

## 3. Not needed today

The speech and voice packages are provider-agnostic. No vendor SDK or API key
is in the code, and development uses local models (Whisper, Piper, Ollama).
A hosted speech or LLM provider would need its own entry here when one is
chosen.

## 4. How to keep this current

Add a row the moment code starts to depend on a new credential, in the same
PR. Then:
- **Proposed names** become real when the code that reads them merges.
- **A cost** moves from "unverified" only with a reference to the provider's
  current pricing page.
